## III. Описание Задания №1 (Задача на оптику/физику)
**Суть:** Спасатель на берегу должен добежать до утопающего в воде за минимальное время. 
*   **Параметры:** Скорость бега по песку, коэффициент замедления в воде, расстояния до воды и до утопающего, угол входа в воду.

## IV. Установка Python и особенности ОС
*   **Версия Python:** Качать с `python.org`. Рекомендуется **3.14** (или любая актуальная из ветки 3.10+). 
    *   ⚠️ **Python 2** устанавливать не нужно! Он несовместим с Python 3 (например, `print` в Python 2 — это оператор, а в Python 3 — функция).
*   **Кроссплатформенность:** Код на Python переносим. Файл `.py`, написанный в Windows, без изменений запустится в Linux и macOS.
*   **Сравнение с компилируемыми языками (C++):** 
    *   В C++ создается исполняемый файл, привязанный к ОС и архитектуре процессора (в Linux — формат ELF, в Windows — MZ/EXE). Перенести `.exe` в Linux и запустить не получится.
    *   Python не создает таких файлов. Код читается интерпретатором, который должен быть установлен в конкретной ОС.
*   **Рекомендация по ОС:** Желательно освоить **Linux** (например, через WSL в Windows). Это стандарт индустрии, а работа в командной строке (CLI) сильно ускоряет разработку и автоматизацию.

## V. Основы синтаксиса Python (Разбор кода)

### 1. Ввод и вывод
*   `print()` — вывод данных на экран.
*   `input("Подсказка: ")` — ввод данных от пользователя. **Важно:** `input()` *всегда* возвращает строку (`str`), даже если пользователь ввел цифры.

### 2. Строки и кавычки
*   Можно использовать одинарные `' '` или двойные `" "` кавычки.
*   **Правило стиля:** В рамках одного файла/проекта лучше придерживаться одного типа кавычек.
*   **Экранирование:** Если внутри строки есть кавычка, используем обратный слэш `\` (например, `"It\'s me"` или `"\"Титаник\""`), либо обрамляем строку кавычками другого типа.

### 3. Переменные и Типизация
*   **Динамическая типизация:** Тип переменной не указывается явно. Он определяется тем, какое значение присвоено переменной *в данный момент*.
*   Одну и ту же переменную можно сначала сделать строкой, а потом числом — Python это позволит.
*   `type(переменная)` — встроенная функция для проверки текущего типа данных.

### 4. Преобразование типов
Поскольку `input()` возвращает строку, для математики ее нужно преобразовывать:
*   `int()` — в целое число.
*   `float()` — в дробное число.
*   `str()` — в строку (нужно для конкатенации при выводе, например: `print("Время: " + str(time))`).

### 5. Комментарии
*   Однострочные комментарии начинаются с символа `#`.

## VI. Как работает Python «под капотом»
*   Python часто называют интерпретируемым языком, но технически это **гибридная модель**.
*   При запуске код компилируется в байт-код (промежуточный код), который сохраняется в кэше (папка `__pycache__`, файлы с расширением `.pyc`).
*   Затем этот байт-код исполняется виртуальной машиной Python (интерпретатором).
*   **Итог:** Python работает медленнее, чем C++ (так как нет прямой компиляции в машинный код процессора), но позволяет писать код гораздо быстрее и проще.
