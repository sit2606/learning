# USE CASE: Расстановка кораблей
═══════════════════════════════════════════════════
Актор:        Игрок
Предусловие:  Игрок выбрал "Начать игру", система отображает пустое поле
              и список доступных кораблей (тип и количество из настроек)
Постусловие:  Все корабли размещены на поле, игра переходит в состояние PLAYER_TURN

Основной сценарий:
  1. Игрок выбирает корабль из списка доступных
  2. Система подсвечивает выбранный корабль
  3. Игрок кликает на клетку поля для размещения носа корабля
  4. Система отображает предпросмотр корабля на поле
  5. Игрок кликает на клетку для размещения кормы корабля
  6. Система размещает корабль на поле и обновляет список доступных
  7. Если остались неразмещённые корабли → переход к шагу 1
  8. Все корабли размещены → сценарий завершён

Альтернативные сценарии:
  5a. Если размещение запрещено (выходит за границы, пересекается
      или касается другого корабля):
      5a.1. Система показывает сообщение "Невозможно разместить корабль"
      5a.2. Возврат к шагу 3

  1a. Если игрок нажимает "Повернуть":
      1a.1. Система меняет ориентацию выбранного корабля (горизонталь/вертикаль)
      1a.2. Возврат к шагу 3

  1b. Если игрок нажимает "Авто":
      1b.1. Система автоматически расставляет все оставшиеся корабли
      1b.2. Сценарий завершён

# USE CASE: Игровой цикл
═══════════════════════════════════════════════════
Актор:        Игрок, Компьютер
Предусловие:  Все корабли расставлены, игра в состоянии PLAYER_TURN
Постусловие:  Все корабли одной из сторон уничтожены,
              переход к сценарию "Завершение игры"

Основной сценарий:
  1. Текущий игрок выбирает клетку на поле противника
     (Игрок — кликом, Компьютер — алгоритмом)
  2. Система обрабатывает выстрел и отображает результат на поле противника
  3. Если все корабли противника уничтожены → переход к "Завершение игры"
  4. Ход передаётся противнику → переход к шагу 1

Альтернативные сценарии:
  2a. Если выстрел попал в корабль:
      2a.1. Система помечает клетку как "Ранен"
      2a.2. Если все клетки корабля поражены:
            2a.2.1. Система помечает корабль как "Убит"
            2a.2.2. Система помечает клетки вокруг корабля как "Промах"
      2a.3. Текущий игрок повторяет ход → переход к шагу 1

  2b. Если выстрел попал в пустую клетку:
      2b.1. Система помечает клетку как "Промах"
      2b.2. Переход к шагу 4

# USE CASE: Настройка игры
═══════════════════════════════════════════════════
Актор:        Игрок
Предусловие:  Игрок выбрал пункт "Настройки" в главном меню,
              система загрузила текущие настройки из settings.json
              (или значения по умолчанию, если файл отсутствует)
Постусловие:  Настройки сохранены в settings.json

Основной сценарий:
  1. Система отображает форму настроек с текущими значениями
  2. Игрок изменяет параметры (размер поля, количество кораблей,
     сложность AI, цвета, шрифты)
  3. Игрок нажимает "Сохранить"
  4. Система проверяет корректность введённых значений
  5. Система записывает настройки в settings.json
  6. Система возвращает игрока в главное меню

Альтернативные сценарии:
  4a. Если значение некорректно (выходит за диапазон, неверный тип):
      4a.1. Система подсвечивает ошибку и показывает допустимый диапазон
      4a.2. Возврат к шагу 2

  3a. Если игрок нажимает "Отмена":
      3a.1. Система отменяет изменения
      3a.2. Система возвращает игрока в главное меню

# USE CASE: Завершение игры
═══════════════════════════════════════════════════
Актор:        Игрок
Предусловие:  Все корабли одной из сторон уничтожены
Постусловие:  Результат игры записан в results.json,
              система находится в главном меню

Основной сценарий:
  1. Система отображает экран результата (победа/поражение)
     с информацией: количество ходов, потопленные корабли
  2. Система записывает результат в results.json
  3. Игрок выбирает действие

Альтернативные сценарии:
  3a. Если игрок нажимает "Играть снова":
      3a.1. Система начинает новую игру → переход к "Расстановка кораблей"

  3b. Если игрок нажимает "Главное меню":
      3b.1. Система возвращает игрока в главное меню

  3c. Если игрок нажимает "Таблица лидеров":
      3c.1. Система отображает таблицу лидеров → переход к "Таблица лидеров"

# USE CASE: Главное меню
═══════════════════════════════════════════════════
Актор:        Игрок
Предусловие:  Приложение запущено
Постусловие:  Игрок перешёл в выбранный раздел

Основной сценарий:
  1. Система отображает главное меню с пунктами:
     "Играть", "Настройки", "Таблица лидеров", "Выход"
  2. Игрок выбирает пункт меню

Альтернативные сценарии:
  2a. Если игрок выбирает "Играть":
      2a.1. Переход к "Расстановка кораблей"

  2b. Если игрок выбирает "Настройки":
      2b.1. Переход к "Настройка игры"

  2c. Если игрок выбирает "Таблица лидеров":
      2c.1. Переход к "Таблица лидеров"

  2d. Если игрок выбирает "Выход":
      2d.1. Система закрывает приложение

# USE CASE: Таблица лидеров
═══════════════════════════════════════════════════
Актор:        Игрок
Предусловие:  Игрок выбрал пункт "Таблица лидеров" в главном меню
              или на экране результата игры
Постусловие:  Игрок вернулся в главное меню

Основной сценарий:
  1. Система загружает данные из results.json
  2. Система отображает таблицу лидеров (имя, победы, поражения),
     отсортированную по количеству побед
  3. Игрок просматривает таблицу
  4. Игрок нажимает "Назад"
  5. Система возвращает игрока в главное меню

Альтернативные сценарии:
  1a. Если файл results.json отсутствует или пуст:
      1a.1. Система отображает сообщение "Нет данных"
      1a.2. Переход к шагу 4
