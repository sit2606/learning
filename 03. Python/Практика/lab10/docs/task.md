Разработайте реализацию игры “Морской Бой” (см. Battleship_(game)), с графическим пользо-
вательским интерфейсом. Программа должна обеспечивать игру пользователя с компьютером.
Вид интерфейса необходимо разработать самостоятельно.
Основные требования:
-  Графический пользовательский интерфейс Tkinter, PyQt или wxPython;
-  Наличие нескольких окон (форм) в приложении;
- Одно из окон должно представлять собой окно настройки приложения под нужды поль-
зователя с указанием параметров и характеристик интерфейса (например, размер окна,
количество кораблей по умолчанию, сложность игры, цвета, размеры и шрифты элемен-
тов пользовательского интерфейса и т.п.);
-  Все параметры конфигурации должны сохраняться в файле JSON и автоматически счи-
тываться при последующем запуске приложения; при отсутствии файла конфигурации
должны применяться значения по умолчанию;
-  Приложение должно вести счёт и по требованию отображать пользователю данные об
игроках с лучшими результатами;
