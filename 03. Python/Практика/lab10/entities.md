# Сущности проекта "Морской бой"

## Список сущностей

| Сущность   | Описание                                    |
| ---------- | ------------------------------------------- |
| Player     | Имя, количество побед и поражений           |
| Board      | Размер, матрица клеток, список кораблей     |
| Cell       | Координаты (row, col), состояние            |
| Ship       | Размер, ориентация, координаты, повреждения |
| Game       | Две доски, текущий ход, состояние игры      |
| Config     | Параметры интерфейса и игры                 |
| GameResult | Результат матча для таблицы лидеров         |

## Состояния

### Cell.state
- EMPTY — пустая клетка
- SHIP — занятая кораблём
- HIT — попадание
- MISS — промах

### Ship
- ALIVE — целый
- DAMAGED — повреждён
- SUNK — потоплен

### Game.state
- SETUP — расстановка кораблей
- PLAYER_TURN — ход игрока
- COMPUTER_TURN — ход компьютера
- GAME_OVER — игра окончена

## Связи

- Game "содержит" 2 → Board (доска игрока и доска компьютера)
- Board "содержит" N×N → Cell
- Board "содержит" N → Ship
- Ship "состоит из" N → Cell (ссылки на клетки)
- Game "связан с" 2 → Player
- GameResult "ссылается на" 2 → Player
