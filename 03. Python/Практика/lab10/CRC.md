| Сущность   | Описание                                    |
| ---------- | ------------------------------------------- |
| Player     | Имя, количество побед и поражений           |
| Board      | Размер, матрица клеток, список кораблей     |
| Cell       | Координаты (row, col), состояние            |
| Ship       | Размер, ориентация, координаты, повреждения |
| Game       | Две доски, текущий ход, состояние игры      |
| Config     | Параметры интерфейса и игры                 |
| GameResult | Результат матча для таблицы лидеров         |


| Имя    | Ответственность                                                                                                                                                                                                                                                                                                                                                                                                                                         | Сотрудничество   |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| Player | Ответственность:                      <br>   - знать имя                           <br>   - знать количество побед              <br>   - знать количество поражений          <br>   - записать победу                     <br>   - записать поражение                  <br>   - предоставить данные для таблицы     <br><br> Сотрудничество:                         <br>   - Game (получает результат матча)     <br>   - GameResult (передаёт данные) | GameResult, Game |

| Имя   | Ответственность                                     | Сотрудничество |
| ----- | --------------------------------------------------- | -------------- |
| Board | Отвественность                                      | Ship, Game     |
|       | - Знать размер поля                                 |                |
|       | - Знать текущее количество кораблей                 |                |
|       | - Проверяет, можно ли разместить корабль            |                |
|       | - Помечает потопленные корабли                      |                |
|       | - Принять выстрел                                   |                |
|       | - Вернуть резльтат выстрела                         |                |
|       | - Знать состояние всех кораблей, размещённых на ней |                |
|       | - Хранить результаты выстрелов                      |                |
|       | -Размещать корабли                                  |                |

| Имя  | Ответственность         | Сотрудничество |
| ---- | ----------------------- | -------------- |
| Cell | Отвественность          | Board          |
|      | - Знать свои координаты |                |
|      | - Знать своё состояние  |                |

| Имя  | Ответственность                                   | Сотрудничество |
| ---- | ------------------------------------------------- | -------------- |
| Ship | Отвественность                                    | Cell           |
|      | - Знать свой размер                               |                |
|      | - Хранить все свои клетки                         |                |
|      | - Рассчитать свой размер  из статуса своих клеток |                |


| Имя  | Ответственность                                                                | Сотрудничество                    |
| ---- | ------------------------------------------------------------------------------ | --------------------------------- |
| Game | Отвественность                                                                 | Player, Board, Config, GameResult |
|      | Текущее состояние игры (Порядок хода, проверить остались ли на доске корабли)  |                                   |
|      | Участвующие игроки                                                             |                                   |
|      | Текущее состояние досок в игре                                                 |                                   |
|      | Сложность ИИ оппонента                                                         |                                   |
|      | При создании получить из сеттингов параметры доски, количество кораблей и т.д. |                                   |
|      | Сообщить итог игры GameResult                                                  |                                   |
|      | Передать доскам параметры, разрешённое количество кораблей                     |                                   |


| Имя    | Ответственность                    | Сотрудничество |
| ------ | ---------------------------------- | -------------- |
| Config | Отвественность                     | Game           |
|        | Создать файл .json                 |                |
|        | Прочитать файл .json               |                |
|        | Предоставить для Game информацию о |                |
|        |                                    |                |
|        |                                    |                |
|        | - Сложность ИИ оппонета            |                |
|        | - Размер доски                     |                |
|        | - Разрешённое количество кораблей  |                |


| Имя        | Ответственность                    | Сотрудничество |
| ---------- | ---------------------------------- | -------------- |
| GameResult | Отвественность                     | Game, Player   |
|            | Хранить результаты игры            |                |
