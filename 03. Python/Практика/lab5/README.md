# Лабораторная работа 5: Игра «Жизнь» Конвея

## Цель работы
Реализация клеточного автомата «Игра Жизнь» Джона Конвея с визуализацией на Python.


**Соседство** — клетки, окружающие данную (8 штук): по горизонтали, вертикали и диагоналям.

## Структура проекта

```
lab5/
├── lab5.py          # Главный скрипт: инициализация, симуляция, визуализация
├── Life.py          # Логика игры: генерация поля, правила, подсчёт соседей
├── Grid.py          # Визуализация: отрисовка сетки, координат, кадров анимации
├── fileLib.py       # Чтение/запись конфигурации из файлов
├── CellInfo.py      # Класс клетки (статус + число соседей)
├── input.txt        # Конфигурация входных данных
├── sim_results.txt  # Результаты симуляции
├── out.gif          # Анимированная GIF-запись поколений
└── requirements.txt # Зависимости (Pillow)
```

## Описание модулей

### CellInfo.py — Клека
Минимальный класс, хранящий состояние одной клетки:
- `_status` (bool) — жива ли клетка
- `_alive_neighbours` (int) — количество живых соседей

### Life.py — Логика игры

| Функция | Описание |
|---------|----------|
| `generate_field(x, y, step, manual)` | Создаёт пустое поле размером x×y с шагом сетки. Если `manual=True`, добавляет предустановленный паттерн (глайдер). |
| `populate_field(field)` | Случайным образом заполняет поле живыми клетками. |
| `populate_field_by_config(field, config)` | Заполняет поле по списку координат из конфигурации. |
| `check_for_neighbours(field)` | Подсчитывает число живых соседей для каждой клетки. |
| `apply_rules(field)` | Применяет три правила Конвея, возвращая новое состояние. |

### Grid.py — Визуализация

| Функция/Класс | Описание |
|---------------|----------|
| `field.draw_grid()` | Рисует пустую сетку на изображении PIL. |
| `draw_by_dictionary(step, field, image)` | Закрашивает зелёным живые клетки по словарю состояний. |
| `draw_coordinates(image, border, length, width, step)` | Добавляет координатные подписи (X, Y). |
| `draw_generation_count(image, count)` | Добавляет номер текущего поколения. |

### fileLib.py — Файловый ввод/вывод

| Функция | Описание |
|---------|----------|
| `openConfig()` | Читает `input.txt`: размеры поля, число поколений, координаты живых клеток. |
| `putConfigToFile(result, length, width, count)` | Сохраняет итоговое состояние в `sim_results.txt`. |

## Формат входного файла (`input.txt`)

```
-- Field Options
- Length
140
- Width
- Generation count
- Start Field Config (Please, provide a coordinates of alive cells)
(1, 3)
(2, 3)
(3, 3)
```

## Формат выходного файла (`sim_results.txt`)

Аналогичный формат, содержит координаты выживших клеток после симуляции.

## Режимы работы

Скрипт `lab5.py` поддерживает два режима:

| Режим | `FILE_MODE` | Описание |
|-------|-------------|----------|
| Файловый | `True` | Конфигурация читается из `input.txt` |
| Ручной | `False` | Параметры задаются в коде; поле заполняется случайно или предустановленным паттерном |

## Запуск

```bash
Использование:

    python lab5.py                 — ручной режим, случайное заполнение

    python lab5.py --file          — файловый режим (чтение из input.txt)

    python lab5.py --manual        — ручной режим с предустановленным паттерном

  

Режимы работы:

    --file    : параметры и начальные координаты считываются из 'input.txt'

    --manual  : предустановленный паттерн (глайдер)

    (без флагов): случайное заполнение поля
```

Результат — файл `out.gif` с анимацией всех поколений и `sim_results.txt` с итоговым состоянием.

## Пример паттерна: Глайдер

В режиме `MANUAL_MODE = True` создаётся глайдер — один из простейших паттернов, перемещающийся по полю:

```
  *
 *
***
```

Координаты: (1,3), (2,3), (3,3), (3,2), (2,1)
