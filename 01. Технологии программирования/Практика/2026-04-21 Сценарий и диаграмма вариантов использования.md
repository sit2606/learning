### Прецедент: **CreateAIRecapForDates** 
Запрос пересказа пропущенной сессии
### Краткое описание: 
Пользователь запрашивает пересказ тех сессий, на которых его не было, на основе существующих конспектов других игроков. 
### Главные актеры: 
Пользователь, Сторонняя нейронная сеть

### Основной поток:
1. Пользователь переходит в меню генерации контента
2. Пользователь отмечает даты, за которые он хочет получить нейропересказ сессии
3. Пользователь пользователь нажимает кнопку "Пересказать"
4. Система направляет в Сторонюю нейронную сеть запрос на пересказ сессии
5. Сторонняя нейронная сеть обрабатывает запрос
6. Сторонняя нейронная сеть возвращает пересказ сессии 
7. Система возвращает пересказ пользователю
### Альтернативные потоки:
NoTokenAvailable
NoMoreGenerationsAvailable
NoConnectionToAI

---
### Альтернативный поток: **CreateAIRecapForDates:NoTokenAvailable**
### Краткое описание: 
Сторонняя нейронная сеть при запросе пересказа возвращает ошибку недостатка токенов для генерации
### Главные актеры:
Сторонняя нейронная сеть
### Предусловия:
1. Пользователь направил запрос на генерацию пересказа сессии
### Основной поток:
 1. Сторонняя нейронная сеть получает запрос на генерацию пересказа сессии и все необходимые для этого данные
2. Сторонняя нейронная сеть проверяет, достаточно ли на балансе токенов для получения пересказа
3. Сторонняя нейронная сеть оповещает о недостатке токенов на балансе Системы
4. Система получает оповещение об ошибке
5. Система формирует сообщение об ошибке для пользователя
