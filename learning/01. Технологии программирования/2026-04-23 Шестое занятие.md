## 🔁 Циклы: итеративные алгоритмические конструкции

### Основные понятия
- **Итерация** — однократное выполнение тела цикла
- **Счётчик цикла** — переменная, отслеживающая количество выполнений
- **Условие выхода** — предикат, определяющий завершение цикла

### Три вида циклов

#### 1. Цикл `for` (счётчик/параметр)
```cpp
for (int i = 1; i <= 5; i++) {
    cout << "i = " << i << endl;
}
```
**Когда использовать**: известно точное количество итераций

**Структура**:
- Инициализация: `int i = 1`
- Условие продолжения: `i <= 5`
- Шаг: `i++`

#### 2. Цикл `while` (с предусловием)
```cpp
int j = 1;
while (j <= 5) {
    cout << "j = " << j << endl;
    j++;
}
```
**Когда использовать**: условие выхода зависит от динамических данных

**Особенность**: проверка условия происходит **до** выполнения тела цикла

#### 3. Цикл `do-while` (с постусловием)
```cpp
int h = 1;
do {
    cout << "h = " << h << endl;
    h++;
} while (h <= 5);
```
**Когда использовать**: гарантированно выполнить тело цикла хотя бы один раз

**Особенность**: проверка условия происходит **после** выполнения тела цикла

### Операторы управления циклом

| Оператор | Действие | Пример использования |
|----------|----------|---------------------|
| `continue` | Пропустить текущую итерацию, перейти к следующей | Пропуск обработки первых 20 элементов |
| `break` | Немедленно выйти из цикла полностью | Досрочное завершение при ошибке |

> ⚠️ **Осторожно с бесконечными циклами!** Забытый инкремент счётчика может привести к зависанию программы.

### Сокращённые операторы инкремента/декремента
```cpp
i++     // постинкремент: сначала использовать, потом увеличить
++i     // преинкремент: сначала увеличить, потом использовать
i--     // постдекремент
--i     // предекремент
i += 2  // сокращение для i = i + 2
```

## 🔍 Алгоритмы сортировки и поиска

### Алгоритмы сортировки

| Алгоритм | Принцип | Плюсы | Минусы |
|----------|---------|-------|--------|
| **Вставками** | Вставка элемента в отсортированную часть | Эффективен на малых и частично отсортированных данных | Неэффективен на больших массивах |
| **Выбором** | Поиск минимума и перемещение в начало | Простота реализации | Высокая вычислительная сложность |
| **Пузырьковая** | Попарное сравнение и обмен соседних элементов | Простота, стабильность | Медленная на больших данных |
| **Слиянием** | Разделение массива, сортировка частей, слияние | Эффективен на больших объёмах, работает с внешней памятью | Требует дополнительной памяти |

### Алгоритмы поиска

#### 1. Линейный поиск (перебор)
- Последовательная проверка каждого элемента
- Сложность: O(n)
- Применим к неотсортированным данным

#### 2. Дихотомический поиск (бинарный)
- Деление отсортированного массива пополам
- Сложность: O(log n)
- Требует предварительно отсортированных данных

> 💡 **Практический совет**: при отладке больших объёмов данных используйте дихотомический подход — делите проблему пополам для локализации ошибки.

## ⚙️ Функции и процедуры в процедурной парадигме

### Структура функции (на примере C++)
```cpp
// Объявление функции
double power(double x) {  // тип возврата, имя, параметры
    double result = pow(x, 3);  // тело функции
    return result;              // возврат значения
}
```

### Функция vs Процедура
| Характеристика | Функция | Процедура |
|---------------|---------|-----------|
| Возвращает значение | ✅ Да | ❌ Нет (`void`) |
| Основное назначение | Вычисление результата | Выполнение действия |
| Пример | `int sum(int a, int b)` | `void printResult(int x)` |

### Область видимости переменных (правило LEGB)

```
Local (локальная)     → внутри функции/блока
↓
Enclosing (внешняя)   → во вложенных функциях
↓
Global (глобальная)   → во всём модуле/программе
↓
Built-in (встроенная) → предопределённые имена языка
```

> ⚠️ **Рекомендация**: избегайте глобальных переменных — они нарушают модульность и усложняют отладку.

### Передача параметров: по значению vs по ссылке

#### По значению (default в C++)
```cpp
void addTwo(int x) {  // копия значения
    x += 2;           // изменяется копия
}
// Исходная переменная не меняется
```

#### По ссылке (C++: `&`)
```cpp
void addTwo(int &x) {  // ссылка на оригинал
    x += 2;            // изменяется оригинал
}
// Исходная переменная меняется
```

| Критерий | По значению | По ссылке |
|----------|-------------|-----------|
| Копирование данных | ✅ Да | ❌ Нет |
| Изменение оригинала | ❌ Нет | ✅ Да |
| Производительность | Ниже (копирование) | Выше |
| Безопасность | Выше | Ниже (риск побочных эффектов) |
