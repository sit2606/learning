# Конспект лекции: «Введение в СУБД PostgreSQL»

## 1. Введение в PostgreSQL

### Основные характеристики
- **PostgreSQL** — свободная, открытая (open source) система управления реляционными базами данных
- Лицензия: либеральная (аналогична BSD/MIT) — можно использовать, модифицировать и даже продавать на её основе коммерческие продукты
- Кроссплатформенность: работает на Windows, Linux, macOS, FreeBSD, Solaris
- Промышленная СУБД: конкурирует с Microsoft SQL Server и Oracle

### Почему PostgreSQL актуальна
- Вендоронезависимость (особенно важно в РФ с 2022 года)
- Активное международное сообщество разработчиков
- Значительный вклад российских разработчиков (Вадим Михеев, Олег Бартунов, Postgres Pro)

## 2. История развития

| Год | Событие |
|-----|---------|
| 1985 | Начало проекта POSTGRES под руководством Майкла Стоунбрейкера (Беркли) |
| 1989 | Первая версия POSTGRES |

| 1994 | Эндрю Ю и Джоли Чен продолжают развитие, добавляют SQL → POSTGRES95 |
| 1996 | Переименование в **PostgreSQL** (версия 6.0) |
| 2017+ | Нумерация версий: одно мажорное число (10, 11, 12... 18) |

### Ключевые фигуры
- **Вадим Михеев** (Красноярск): автор MVCC, механизма VACUUM, WAL, триггеров
- **Олег Бартунов** (МГУ): основатель Postgres Pro, локализация, полнотекстовый поиск, JSON

## 3. Архитектурные особенности

### Клиент-серверная модель
```
Клиенты (приложения) ↔ Сервер PostgreSQL ↔ Хранилище (диск)
```

### OLTP vs OLAP
| Параметр | OLTP | OLAP |
|----------|------|------|
| Назначение | Транзакционная обработка | Аналитическая обработка |
| Характер запросов | Много коротких транзакций | Сложные агрегирующие запросы |
| Требования | Минимальное время отклика | Обработка больших объёмов данных |
| Примеры | Мессенджеры, заказы, платежи | BI-системы, отчётность |

### 🔑 MVCC (Multi-Version Concurrency Control)
**Многоверсионное управление одновременным доступом**

- При обновлении/удалении строки создаётся новая версия, старая помечается как «мёртвая»
- ✅ Преимущества: высокая скорость, минимизация блокировок, согласованное чтение
- ⚠️ Недостаток: таблица «распухает» из-за мёртвых версий строк

**Решение: VACUUM**
```sql
VACUUM table_name;        -- Помечает свободное место для повторного использования
VACUUM FULL table_name;   -- Полная дефрагментация (требует эксклюзивной блокировки)
```

### 🔑 WAL (Write-Ahead Log) — журнал предзаписи
- Все изменения сначала записываются в лог на диске, затем — в основные файлы данных
- Гарантирует восстановление после сбоя до консистентного состояния
- Позволяет реализовывать Point-in-Time Recovery (восстановление на момент времени)

## 4. Версионность и обновления

### Политика релизов
- **Мажорная версия** (16, 17, 18): выходит раз в год, содержит новый функционал
- **Минорная версия** (18.1, 18.2...): исправления ошибок и безопасности, выходят ежеквартально

### Рекомендации по выбору версии
```
✅ Для обучения/тестов: последняя стабильная (18.4)
✅ Для продакшена: проверенная версия (15.3) — баланс стабильности и функциональности
❌ Не использовать альфа/бета-версии в продуктивных системах
```

## 5. Возможности PostgreSQL

### Поддержка стандартов
- Соответствие стандарту SQL (ANSI/ISO): от SQL-92 до SQL:2023
- Поддержка 177+ обязательных возможностей стандарта

### Программные объекты
| Объект | Описание |
|--------|----------|
| Таблицы | Хранение данных с первичными/внешними ключами |
| Представления (Views) | Виртуальные таблицы на основе запросов |
| Функции | Возвращают значение, выполняются в одной транзакции |
| Процедуры | Могут содержать несколько транзакций (с v11) |
| Триггеры | Автоматически выполняемые функции при DML/DDL-событиях |
| Индексы | Ускорение поиска (B-tree, Hash, GiST, GIN, BRIN и др.) |

### Расширяемость
- Создание пользовательских типов данных
- Написание функций на C, Python, Perl, Java и др.
- Установка расширений (postgis, pg_stat_statements и 100+)

## 7. Практическая часть: установка и настройка

### Рекомендуемая версия для курса
- **PostgreSQL 15.3** + **pgAdmin 4** (в комплекте установщика)

### Шаги установки (Windows)
1. Скачать установщик из папки «Программное обеспечение» или с [postgresql.org](https://www.postgresql.org/download/)
2. Запустить installer → Next → Next (параметры по умолчанию)
3. Задать пароль для пользователя `postgres` (запомнить!)
4. Убедиться, что отмечен компонент **pgAdmin**
5. Завершить установку

### Проверка установки
```sql
-- В pgAdmin: открыть Query Tool и выполнить
SELECT version();
-- Ожидаемый результат: "PostgreSQL 15.3 ..."
```

### Развёртывание учебной БД (через psql)
```cmd
cd "C:\Program Files\PostgreSQL\15\bin"
psql -U postgres -d postgres -f "путь\к\файлу\demo.sql"
```
⚠️ При вводе пароля символы не отображаются — это нормально, просто введите и нажмите Enter.
