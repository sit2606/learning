
Этот репозиторий содержит учебные материалы, конспекты лекций, практические работы и исходный код, структурированные по учебным дисциплинам.

---

## 📂 Структура репозитория

### 📁 `01. Технологии программирования`
Материалы по инженерии программного обеспечения, сбору требований и моделированию систем.
- **Лекции:** Конспекты занятий.
- **Практика:** Задания по разработке концепций, пользовательских историй, функциональных требований, а также набор UML и SADT диаграмм (в формате `.svg`).

### 📁 `02. Введение в базы данных`
Материалы по проектированию, нормализации и реализации реляционных баз данных.
- **Лекции:** Конспекты занятий.
- **Практика:** Директории с лабораторными работами, включающие схемы таблиц, описания баз данных, SQL-скрипты и вспомогательные материалы.

### 📁 `03. Python`
Начальный этап изучения языка программирования Python.
- **Лекции:** Конспекты базовых занятий.
- **Практика:** Исходный код лабораторных работ (`.py`).

---

> 💡 **Примечание:** Репозиторий организован в формате хранилища Obsidian, но все текстовые файлы (`.md`), SQL-скрипты (`.sql`), код (`.py`) и диаграммы (`.svg`) можно просматривать напрямую через стандартный интерфейс GitHub без необходимости установки дополнительных приложений.
